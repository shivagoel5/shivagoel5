## How to navigate

**SignalLoop** → [`shivagoel5/signalloop`](https://github.com/shivagoel5/signalloop)
- **README** — the hypothesis I was testing, an honest map of what's live vs. simulated vs. AI, and the list of what I still need to validate with real PMMs before any of it is a finding.
- **Marketing artifacts** — `data/companies/` holds the strategy inputs as structured files: ICP, audiences with buying role and job to be done, positioning, value proposition, product proof, competitive alternative, message hypotheses and constraints.
- **Code** — deterministic analytics, guardrails and significance testing in `lib/`; the Marketing Agent and Content Agent, their tools and output validation in `lib/agents/`.
- **Write-ups** — [How it works](https://signalloop-dun.vercel.app/how-it-works) and [Behind the build](https://signalloop-dun.vercel.app/behind-the-build) on the live site.
